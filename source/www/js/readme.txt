■ 概要

戦闘突入時に画面を回転させるエフェクトを追加します。


■ 使用方法

1. KMS_SpiralEncount.js を、プロジェクトの js/plugins
   フォルダにコピーしてください。

2. RPG ツクール MV のプラグインマネージャから
   「KMS_WaterMapEffect」を追加してください。


■ 動作確認環境

RPG ツクール MV 1.3 以降

Windows 8.1
  - エディタテストプレイ
  - Mozilla Firefox 41.0.2
  - Google Chrome 46.0

※ WebGL をサポートしていない環境では動作しません。


■ 設定項目

[Speed]
回転の速度です。
値が大きいほど回転が速くなります。

[Radius]
エフェクトの適用範囲です。
値を大きくするほど、派手に回転しているように見えます。
1.0 で画面サイズと同程度にかかるようになります。

[Show characters]
エフェクト時にプレイヤーやイベント等を表示するか指定します。
戦闘背景にマップ画面を表示している場合、この設定でキャラクターを
表示すると戦闘背景にも表示されます。
